# JustSpeak — Frontend

## طريقة التشغيل محليًا

```bash
cd frontend
npm install
npm run dev
```

بعدها افتح المتصفح على `http://localhost:3000`

## اللي اتعمل في الـ Feature دي

- هيكل مشروع Next.js أساسي (App Router)
- دعم لغتين (عربي/إنجليزي) مع تبديل تلقائي للاتجاه RTL/LTR
- صفحة رئيسية (Landing) مطابقة للـ Mockup المتفق عليه
- صفحة تسجيل دخول (شكل بس، من غير اتصال حقيقي بالسيرفر لسه)
- ألوان وخطوط متوافقة مع الهوية البصرية (أزرق + أبيض/رمادي، Cairo/Inter)

## بيئة العمل

مفيش `.env` مطلوب في المرحلة دي لأن مفيش اتصال بسيرفر حقيقي لسه.
هنضيفه في Feature الـ Auth API.

## قرار تقني بسيط اتخذته في الخطوة دي

بدل ما أضيف مكتبة i18n جاهزة (زي next-intl) من الأول، عملت
Context بسيط في `lib/i18n.tsx` بيدير الترجمة والاتجاه. ده أسهل
تفهمه وتعدل عليه دلوقتي، ولو المشروع كبر واحتجنا features زي
تعدد صيغ الجمع أو تنسيق تواريخ معقد، وقتها ننتقل لمكتبة جاهزة.
